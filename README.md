# Recycle Here 

Plataforma web desenvolvida como projeto acadêmico para facilitar a localização de pontos de coleta e reciclagem

## Objetivo
Permitir que usuários encontrm pontos de coleta inicialmente em Sorocaba, de acordo com a regão e o tipo de material que desejam descartar

## Tecnologias
Nesta primeira etapa serão utilizadas:

- HTML5
- CSS
- JavaScript
- Git e GitHub
